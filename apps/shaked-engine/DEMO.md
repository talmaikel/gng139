# ריצת ההדגמה — מה להציג, ובאיזה סדר

## איפה זה רץ

**מקומית, עם מנהרה ציבורית.** אין שרת מתארח, ולא צריך אחד להדגמה:

```bash
# 1 · בסיס הנתונים
cd apps/shaked-engine && docker compose up -d db

# 2 · השרת
cd backend && .venv/bin/uvicorn app.main:app --port 8000

# 3 · המסכים — מגישים גם את ה-API באותו מקור
cd ../frontend && npm run dev

# 4 · כתובת ציבורית, בלי חשבון ובלי הגדרה
cloudflared tunnel --url http://localhost:3000
```

הפקודה האחרונה מדפיסה כתובת `https://<...>.trycloudflare.com` — **זו הכתובת
שמשתפים.** היא מתחברת מחדש לבד אחרי נפילת רשת (נבדק).

**הדפדפן מדבר עם מקור אחד בלבד.** ‏Next מעביר את `/api/*` לשרת, ולכן אין
CORS ואין תלות ב-`localhost` — האפליקציה עובדת ממחשב אחר ומטלפון.

> **הכתובת ציבורית לכל מי שיש לו אותה.** ההגנה היא ההתחברות בלבד, ומשתמש
> ההדגמה נושא סיסמה חלשה. **להפעיל את המנהרה בזמן ההדגמה ולסגור אחריה** —
> `Ctrl+C` על `cloudflared`.


נבנה ב-13.09 אחרי ריצת קבלה. המטרה: **אפס שליפות ארכיון חיות במהלך
ההדגמה.** ‏684 מ-699 המועמדים דורשים שליפת תיק בזמן המסירה, והיא לוקחת
עד 20 שניות ויכולה להיכשל. לארבעת המועמדים שלמטה התיק **כבר נשלף
ושמור**, ולכן המסירה שלהם מיידית.

## הסדר המומלץ

1. **לצייר** את האזור. להראות את מד השטח החי, ואת האזהרה האדומה כשחורגים
   מ-250 דונם — ‏MAP-01 מסרב, וזה פיצ׳ר.
2. **תנאים והעדפות.** מינימום דירות 14, ואז סדר לפי תקרת 400% יורד.
   להראות את עמודת ״נימוק הסדר״: *״תקרת 400%: 11,301 מול 9,776 בבא
   אחריו״* — ‏SEL-01 דורש נימוק לכל בחירה.
3. **מסירה** של שלושה מהארבעה. היתרה 3 → 0, וההודעה אומרת כמה נוכה.
4. **מסירה רביעית** → 402 עם ״יש לרכוש חבילה כדי להמשיך״.
5. **לפתוח תיק.** שרשרת 1–9 עם ציטוט עמוד לכל שער, טבלת ״מאיפה הגיע כל
   מספר״ עם עמודת ״מכריע?״, פירוק העלויות, ופרק הפערים.
6. **להוריד Excel.** לשנות מחיר מכירה בתא הכחול ולהראות את המרווח זז —
   זו הנקודה החזקה: הלקוח בודק אותנו, לא מאמין לנו.

## מה להגיד כשמשהו נראה חסר

**התרחיש מסומן ״אינו נמסר כתוצאה״** — וזה נכון. שתי הנחות אינן ידועות:
שטח דירה קיימת ממוצע (נדרש מגרמושקה, ‏B3) והיטל השבחה (שאלה פתוחה
לעו״ד, ‏L1). המודל מחשב, ואינו מתחזה.

**רוב המועמדים ״דורשים מדידה״** בקומות — טווח רוחב הרחוב חוצה שורה
בטבלת המדיניות. זה D1, וזה ידני.

## אם בכל זאת נלחץ ״מסור לי״ על מועמד אחר

תיק הבניין ייושלף חי. הכפתור יאמר **״שולף תיק בניין…״** ולא ״מוסר…״,
והתשובה תגיע תוך 10–20 שניות. אם הארכיון יסרב — **503** עם ״אפשר לנסות
שוב בעוד כמה דקות״ וכפתור ניסיון חוזר, והיתרה **לא** תיגרע.
