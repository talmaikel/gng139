# פיילוט 01 — 10 תיקי בניין בהרצליה

הניחו כאן עד עשרה קובצי PDF ציבוריים של היתרי בנייה או תכניות היתר סרוקות,
בתיקייה `input`. לכל קובץ יש להוסיף שורה ב־`manifest.csv`.

הקובץ אינו צריך לכלול מידע פרטי: רק מסמך עירוני ציבורי, כתובת, מזהה תיק וקישור
המקור הציבורי שממנו הורד. אין לשנות את שם העמודות בקובץ הרישום.

המדגם צריך לכלול גם תיקים קלים וגם לפחות שני תיקים סרוקים או חלקיים, כדי למדוד
בכנות את שיעור הכשל והצורך בבדיקה אנושית.

אחרי שמילאתם את התיקייה ואת קובץ הרישום, מפעילים:

```powershell
.venv/Scripts/python.exe scripts/run_local_pilot_batch.py
```

התוצאות נשמרות בתיקיית `output` ובקובץ `batch-results.json`. אין קריאת API בשלב זה.
