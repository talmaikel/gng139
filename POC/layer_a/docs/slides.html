מה נעשה היום, ומה למדנו

חלופת שקד · הרצליה

היום עברנו מ"האם אפשר" ל"כמה יש". הצינור אומת מקצה לקצה, ואז הורץ על כל העיר — והמעבר מקנה מידה קטן לגדול הוא שחשף את הממצאים החשובים ביותר, לטובה ולרעה.

חמש התובנות

  1. השטח הקיים אינו תנאי סף — הוא תמחור.

    סעיף 70א מונה שלושה תנאים, ושטח בנוי אינו אחד מהם. הוא נכנס רק ב"חישוב הזכויות". רדפנו אחריו חצי יום כאילו הוא חוסם את המשפך — הוא נוגס רק בדוח, על שלושה בניינים לעסקה.

  2. עיריית הרצליה כבר מפרסמת את מה שחיפשנו.

    פורטל ArcGIS ציבורי דרך API תקני ומתועד: 14,072 מבנים עם מספר קומות, ו-14,624 נקודות כתובת עם מספר דירות ב-92% כיסוי. שני השדות שחסרו לנו. חוקי לחלוטין, בניגוד ל-GIS שנפסל.

  3. מפת המדיניות היא השער החזק והזול ביותר.

    גאו-רפרנס מתוויות שמות הרחובות שבמפה עצמה, RMS 20.7 מ'. היא חותכת 83% מהמועמדים באפס פניות, ומאומתת ממקור סטטוטורי בלתי תלוי.

  4. הארכיון כמעט אינו מחזיק תכניות של בניין שלם מלפני 1980.

    12 מסמכים נפתחו בשתי שכונות; אחד בלבד היה תכנית בניין שלם — ושל בניין פסול. זה חסם מקור, לא חסם טכני ולא משפטי.

  5. קנה מידה הורג הנחות.

    שלוש מסקנות שנמדדו על 7 מקרים התבררו כשגויות, ושני באגים התגלו רק כשהמשפך רץ על 904. גם "אין שדה דירות בפורטל" היה שגוי — הוא נמצא בסריקה חוזרת. כל ממצא נבדק מול מקרה מוכר לפני שהוא נכנס.

למה כך

מהירותהמתנה למשתמש יורדת מ-9.3 דקות לאפס. זה שינוי ברמת מוצר, לא אופטימיזציה.
חוקיותמארח האינדקס אינו מפרסם robots.txt; מארח המסמכים אומר Disallow: /. הגבול בין השכבות עובר בדיוק שם.
עלותהקמה ~1.5 שעות ו-21 פניות. נקודת איזון מול המפל: 20 סריקות.
יכולת חדשהדירוג עירוני והתראות שינוי — דברים שהמפל לא איפשר כלל.
תנאי אחד שאינו ניתן לוויתור: אימות חי לפני מסירה.

השכבות הן צילום מצב, והטריות היא הסיכון שלהן. תיק 475 עבר את כל השערים ונפסל בגלל היתר חיזוק מ-2024 — שהתגלה רק בפתיחה חיה. שלוש פניות על שלושת המועמדים הסופיים, בכל דוח.

האלגוריתם

בזמן שאילתהאפס פניות חיצוניות — הכול נקרא מהשכבות המקומיות

# --- שכבה א' · נבנית מראש, אפס פניות לארכיון ---
A = parcels
    .has_building()                    # שכבת מבנים עירונית
    .floors >= 2  and  status not in {הרוס, בבנייה}
    .gross >= 250                      # טביעת רגל × קומות
    .apartments >= 4                   # num_aprt · 92% כיסוי
    .zoning is residential_approved     # XPlan שכבה 4
    .not מבנה_לשימור                    # Shimour שכבה 2
    .policy_map in {צהוב, צהוב_בהיר}     # הר/2323 · חותך 83%
# 19,066 → 904 → 700

# --- זמן שאילתה ---
cand = A.within(center, radius).join(B)        # B = היסטוריית היתרים
cand = [c for c in cand
        if c.permit_year < 1980                  # שער חוק
        and not c.strengthened_by_permit]        # היתר שהופק בלבד

for c in cand:
    c.existing = c.gross * 0.669               # אומדן · כויל n=1
    c.envelope = setback_envelope(c)           # רגיש: 3מ' מול 4מ'
    c.value    = min(4*c.existing, c.envelope) - c.allocation
    c.bound_by = '400%' if 4*c.existing <= c.envelope else 'מעטפת'
    c.conf     = 'היתר' | 'מובנה' | 'אומדן'
    c.pair     = adjacent_same_street(c)       # 20% מהצמידויות

rank    = sort(cand, key=(-value, conf, -pair))
