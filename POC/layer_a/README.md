# שכבה א' — כשירות גיאומטרית לחלופת שקד

סינון מועמדים לחלופת שקד בהרצליה **בלי אף פנייה לארכיון העירוני**.

```
19,068 חלקות → 904 (מפה, קומות, ייעוד, שימור) → 700 (≥4 יחידות דיור)
```

## למה זה קיים

תנאי הסף של סעיף 70א הם שלושה, ו**שטח בנוי אינו אחד מהם** — הוא נכנס רק ב"חישוב הזכויות".
לכן כל מבחן הכשירות מלבד שניים (שנת היתר, וחיזוק בהיתר) רץ ממקורות פתוחים בלבד.

## הרצה

```bash
python scripts/fetch_sources.py     # ~106MB ל-raw/ · כ-20 דקות · אפס פניות לארכיון
python scripts/build_layer_a.py     # → data/survivors.json
python tests/test_layer_a.py        # חייב לעבור אחרי כל רענון
```

תלויות: `shapely`, `pyproj`, `pymupdf`, `pillow`, `numpy`.

## המקורות

| מקור | מה נלקח | מגבלה |
|---|---|---|
| GovMap WFS `Parcels_ITM` | גבול ושטח חלקה | מספרי חלקות משתנים עם השנים |
| ArcGIS עירוני `buildings_reka` | `Num_floors`, טביעת רגל, `status` | ספירה פיזית — אינה מיישמת את כלל קומת העמודים שבחוק |
| ArcGIS עירוני `מספרי_בתים_חדש/43` | `num_aprt`, `amudim` | 92% כיסוי · **לפי כניסה ולא לפי בניין** · 999 הוא ערך סנטינל |
| iplan XPlan שכבה 4 | ייעוד + סטטוס אישור | רק תכניות מהעידן המקוון |
| iplan Shimour שכבה 2 | שימור | **רק "מבנה לשימור" פוסל** — אזורי עתיקות הם סימון |
| הר/2323 עמ' 7 | קטגוריית מדיניות | ראסטר מגאו-רפרנס · RMS 20.7 מ' |

הפורטל של העירייה הוא **ArcGIS Online ציבורי** ונקרא דרך ה-REST API התקני.
זה שונה מהותית מה-GIS העירוני, שדורש התחזות ללקוח שלו ולכן נפסל.

## מפת המדיניות

`data/policy_map_affine.npy` היא התמרה אפינית מקואורדינטות PDF ל-EPSG:2039,
שנלמדה מ-11 תוויות שמות רחובות שעל המפה עצמה מול גיאומטריית הרחובות ב-OSM.
**היא מכוילת ל-`data/strategic.pdf` בדיוק** — החלפת הקובץ מחייבת כיול מחדש.

הסיווג נעשה בדגימת דיסק ברדיוס 15 מ' עם צבע קרוב ורוב, **לא בהתאמת פיקסל מדויקת** —
פיקסל בודד נופל על קצוות מוחלקים ופוסל מועמדים כשירים.

## מה השכבה הזאת לא עושה

- **אינה קובעת שטח קיים.** הוא אומדן: `טביעת_רגל × 0.669 × קומות`, ומקדם ההמרה כויל על **נקודת אמת אחת**
- **אינה קובעת רוחב רחוב.** `scripts/street_widths.py` נשמר אבל **הפלט שלו לא** — ריצה עירונית הפיקה
  מספרים שגויים (`max` על פני כל החזיתות) ונמשכה בחזרה. לפני הרצה מחדש נדרשים כלל ברור
  איזו חזית קובעת, ועוד נקודות אמת מעבר למנדלבלט 12 מ'
- **אינה בודקת שנת היתר וחיזוק.** אלה שני שערי החוק שדורשים את הארכיון

## הארכיון

`handasi.complot.co.il` אינו מפרסם robots.txt. `archive.gis-net.co.il` מפרסם `Disallow: /`.

**אל תריץ סריקה יזומה מול הארכיון.** ב-12.09.2026 נוסתה סריקה של 674 תיקים בקצב של פנייה
ל-11 שניות; האתר החזיר CAPTCHA ואז סירוב, ו-31 עמודים בלבד התקבלו. פתיחת תיקים היא
**לפי דרישת לקוח בלבד, עם מטמון קבוע**. הופעת CAPTCHA היא אות עצירה, לא תנאי לניסיון חוזר.

## פרטיות

`scripts/extract_tiks.py` מחלץ עובדות מעמודי תיק **ומדלג על עמודת שם המבקש**.
אין לשמור HTML גולמי של הארכיון אחרי החילוץ.
